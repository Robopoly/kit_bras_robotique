# 🚀 Installation et lancement rapide

## Installation automatique
```bash
# Installer pygame
pip install pygame

# Ou utiliser le fichier requirements
pip install -r requirements.txt
```

## Lancement

### Option 1: Script principal
```bash
python space_invaders_simulator.py
```

### Option 2: Démonstration avec informations
```bash
python demo.py
```

### Option 3: Depuis le répertoire parent
```bash
python space_invaders_simulator\space_invaders_simulator.py
```

## Résolution de problèmes

### Pygame non installé
```bash
pip install pygame
```

### Erreur de chemin
Assurez-vous d'être dans le bon répertoire :
```bash
cd tools/space_invaders_simulator
python space_invaders_simulator.py
```

### Python non trouvé
Vérifiez que Python est installé et dans le PATH :
```bash
python --version
```
